# Interfaces & Polymorphism

## Interface
- An interface is a contract that defines what operations an object provides without exposing how they are implemented.
- It describes capabilities, not implementation details.

## Why Interfaces Matter
- Reduce coupling.
- Allow different implementations to be used interchangeably.
- Help localise change.

## Polymorphism
- Polymorphism means different objects can respond to the same request in different ways.
- The caller uses one common interface while each object provides its own implementation.

## Python Perspective
- Python often uses duck typing: "If an object provides the required behaviour, it can be used."
- Formal inheritance is less important than satisfying the expected behaviour.

## Relationship to Previous Lessons
- Composition often works through interfaces.
- Interfaces define how collaborating objects communicate.
- Polymorphism makes systems extensible without changing existing client code.

## Mental Model
- Interface = Promise or contract.
- Polymorphism = Many implementations of the same promise.
