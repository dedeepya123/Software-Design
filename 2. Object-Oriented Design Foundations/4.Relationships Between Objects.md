# Relationships Between Objects

## Definition
- A relationship describes how two or more objects interact, depend on, or collaborate with each other.

## Why Relationships Exist
- Large problems are solved by many specialised objects working together.
- Relationships enable collaboration without duplicating responsibilities.

## Key Relationship Types (Intuition)
- Dependency: Temporary use of another object.
- Association: Objects know about each other but have independent lifetimes.
- Aggregation: One object contains others, but they can exist independently.
- Composition: One object owns parts whose lifetime is closely tied to the whole.

## Design Principles
- Objects should collaborate instead of taking over each other's responsibilities.
- Relationships should be purposeful and minimise unnecessary coupling.
- Prefer asking another object to perform work rather than modifying its internal state directly.

## Connection to Phase 0
- Modularity divides responsibilities.
- Cohesion keeps each object focused.
- Coupling is determined largely by object relationships.
- Abstraction and encapsulation guide how objects interact.

## Mental Model
- Think of objects as specialists in a team.
- They solve larger problems through collaboration, not by becoming one giant object.
