# What is a Class?

## Definition
- A class is a reusable definition that specifies the structure, behaviour, and rules shared by similar objects.

## Purpose
- Avoid duplicating behaviour.
- Define a common structure.
- Enforce object invariants.
- Provide a consistent way to create related objects.

## Class vs Object
- Class:
  - A definition or template.
  - Defines structure and behaviour.
  - Exists once.
- Object:
  - A runtime instance.
  - Holds its own state and identity.
  - Uses behaviour defined by the class.

## Key Insight
- Classes define.
- Objects exist.

## Relationship to Previous Lessons
- Classes help achieve modularity.
- Good classes have high cohesion.
- They expose abstractions.
- They encapsulate state and behaviour.
- They localise changes by grouping related logic.

## Mental Model
- A class is like a university rulebook.
- Objects are the individual students created according to those rules.
