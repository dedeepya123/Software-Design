# Lesson 3: State, Behaviour & Identity

## State
- State is the data representing an object's current condition.
- State changes throughout the object's lifetime.
- Think of state as the object's memory.

## Behaviour
- Behaviour defines what an object can do.
- Behaviour is responsible for changing state in valid ways.
- Good behaviour protects invariants and enforces business rules.

## Identity
- Identity uniquely distinguishes one object from another.
- Two objects may have identical state but different identities.
- In Python:
  - == compares equality (typically based on value/state).
  - is compares identity (whether two references point to the same object).

## Relationship Between Them
- Behaviour operates on state.
- Identity persists even as state changes.
- Together they form the essence of an object.

## Mental Model
- State = Memory
- Behaviour = Capabilities
- Identity = Individual existence
