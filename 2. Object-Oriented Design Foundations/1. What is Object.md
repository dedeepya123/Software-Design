# What is an Object?

## Definition
- An object is a self-contained entity that combines state and behaviour and has a unique identity.

## Three Characteristics
1. State
   - The data representing the current condition of the object.
2. Behaviour
   - The operations the object can perform.
3. Identity
   - A unique existence that distinguishes it from other objects, even if they have the same state.

## Why Objects Exist
- They group related data and behaviour together.
- They model real-world or domain concepts.
- They make large systems easier to organise and reason about.

## Relationship to Phase 0
- Objects are modular units.
- Good objects have high cohesion.
- Objects communicate through controlled interactions (low coupling).
- Behaviour exposes abstractions.
- State is protected through encapsulation.

## Mental Model
- Think of an object as a small responsible agent that owns its data, performs its own work, and collaborates with other objects to solve larger problems.
