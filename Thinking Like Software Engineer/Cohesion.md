# Cohesion

## Definition
- Cohesion is the degree to which the responsibilities inside a module belong together.

## High Cohesion
- A module has one clear responsibility.
- Related functionality stays together.
- Easier to understand, test, maintain, and modify.

## Low Cohesion
- A module contains unrelated responsibilities.
- Difficult to understand and maintain.
- Changes often affect unrelated functionality.

## Key Insight
- High cohesion localises change.
- If a feature changes, ideally only one module needs to change.

## Coupling vs Cohesion
- Coupling measures dependencies between modules.
- Cohesion measures how well the responsibilities inside a module fit together.

## Mental Model
- High cohesion: A well-organised department where everyone works toward the same goal.
- Low cohesion: A room full of unrelated tools and objects mixed together.
