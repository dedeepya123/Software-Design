# What is Software Design?

## Software:
- A system built to solve a problem.

## Programming:
- Focuses on implementing functionality.
- Answers: "How do I make this work?"

## Software Design:
- Focuses on organizing software so it is easy to understand, modify, extend, test, and maintain.
- Answers: "How do I make future changes easier?"

## Core Insight:
- Software is written once but modified many times.
- Design exists to reduce the cost and risk of those future changes.

## Mental Model:
Programming -> Makes software work.
Software Design -> Makes software survive change.
