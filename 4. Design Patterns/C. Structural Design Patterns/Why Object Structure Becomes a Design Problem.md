# Why Object Structure Becomes a Design Problem

## Core Idea
- Creating good objects is only the first step.
- The larger challenge is organising how objects interact and collaborate.

## Common Structural Problems
- Incompatible interfaces
- Tight coupling
- Large object hierarchies
- Growing functionality
- Complex subsystems
- Memory duplication
- Access control

## Key Design Questions
1. How can incompatible interfaces work together?
2. How can abstractions and implementations evolve independently?
3. How can individual objects and groups be treated uniformly?
4. How can behaviour be added without modifying existing code?
5. How can a complex subsystem be simplified?
6. How can shared data reduce memory usage?
7. How can access to an object be controlled?

## Key Insight
- Structural patterns are about organising relationships between objects so systems remain flexible, maintainable and easier to evolve.
