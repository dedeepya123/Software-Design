``` text

Am I solving an object creation problem?

│
├── Only one instance should exist?
│      → Singleton
│
├── The client shouldn't create the object?
│      → Factory Method
│
├── Need a compatible family of related objects?
│      → Abstract Factory
│
├── One object is complex to configure?
│      → Builder
│
└── I already have a similar object?
       → Prototype

```
