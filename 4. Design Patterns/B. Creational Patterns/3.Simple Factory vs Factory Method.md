# Simple Factory vs Factory Method

## Simple Factory
- Centralises object creation in one factory.
- Easy to understand and implement.
- Client delegates creation to the factory.
- Factory often grows as new products are added.

## Factory Method (GoF)
- Delegates creation to specialised creator classes.
- Each creator is responsible for one product.
- Supports extension by adding new creators rather than modifying one large factory.
- Often implemented using inheritance and abstract methods.

## Recognition Questions
- Is there one central factory with many conditionals? → Simple Factory.
- Does each subclass implement its own creation method? → Factory Method.

## Python Perspective
- Python often uses functions, dictionaries or callables instead of the classic GoF inheritance structure.
- Focus on the design intent: separating creation from use and making creation extensible.

## Key Insight
- Factory Method is not fundamentally about inheritance.
- It is about making object creation extensible while keeping clients independent of concrete implementations.
