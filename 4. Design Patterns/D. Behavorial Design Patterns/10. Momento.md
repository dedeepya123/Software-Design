# Memento Pattern

## Problem
- Need to save and restore an object's previous state.
- Internal implementation should remain hidden.

## Core Idea
- Let the object create and restore snapshots of its own state.
- Store snapshots externally without exposing their contents.

## Participants
- Originator: Creates and restores snapshots.
- Memento: Stores a snapshot of state.
- Caretaker: Maintains the history of snapshots.

## Recognition Questions
- Is undo/redo or rollback required?
- Should previous states be restored?
- Must encapsulation be preserved?

## SOLID Principles
- SRP: Originator manages state; caretaker manages history.
- OCP: New state fields require changes only in save/restore logic.
- Encapsulation: Internal state remains hidden from external objects.

## Comparison
- Command: Encapsulates actions.
- State: Represents current behavior.
- Memento: Captures previous state.

## Key Insight
- Memento preserves encapsulation while enabling undo and state restoration.
