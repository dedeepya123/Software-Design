# What is a Design Pattern?

## Definition
- A design pattern is a reusable design solution to a recurring software design problem.
- It describes how responsibilities and collaborations should be organised, not exact code.

## Why Patterns Exist
- Software problems repeat.
- Engineers repeatedly discovered similar successful solutions.
- These proven solutions were documented as patterns.

## Pattern vs Principle
- Principles (e.g., SOLID) guide good design.
- Patterns provide reusable structures that apply those principles.

## Pattern vs Algorithm
- Algorithm: Organises computation.
- Design Pattern: Organises object collaboration.

## Pattern vs Library
- Library: Reusable code.
- Pattern: Reusable design idea.

## Pattern vs Framework
- Framework: Complete application structure.
- Pattern: Small reusable design approach that can exist inside a framework.

## Key Insight
- Patterns are discovered from repeated experience, not invented arbitrarily.

## Mental Model
- A design pattern is like a well-worn hiking trail: many engineers independently found that this route consistently solves a recurring problem.
